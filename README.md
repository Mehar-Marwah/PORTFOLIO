# Mehar’s Eulonar

Static portfolio for Mehar Marwah, including projects, credentials, Luke the portfolio guide, and a downloadable resume.

## Upload

Extract this ZIP and upload all files to the root of your GitHub repository. Keep index.html, style.css, app.js, images and the resume together. No installation or build step is required.

The .nojekyll file is included for static hosting.

## Edit

- index.html: page content and contact links
- style.css: layout, colours and responsive styling
- app.js: project details, credentials and Luke’s portfolio replies
- Mehar-Marwah-Resume.docx: downloadable resume

Luke uses preset portfolio replies. No API key or server is required.
